Design: Elegant blue and white
Technology: HTML5 and CSS3 only (no JavaScript)

PROJECT FILES
-------------
index.html   - Home page
about.html   - About page
blog.html    - Two complete blog articles with images
contact.html - Contact details
style.css    - Shared website styling and responsive layout

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the Student_Life_Blog folder.
3. Double-click index.html.
4. The website opens in your browser.
5. Use the navigation links to visit Home, About, Blog, and Contact.

NOTES
-----
- Keep all HTML files and style.css in the same folder.
- An internet connection is needed for Google Fonts and the remote Unsplash images.
- This project uses HTML and CSS only. The email link opens the visitor's email application.
- You may edit the text and replace image URLs in the HTML files.
